This Policy Covers This Website Itself: The Pages Served From This Address. It Is A Handful Of Static Pages Hosted On GitHub Pages, And It Collects Nothing About You.

What This Site Collects

Nothing. The Pages Are Plain HTML. Hosting

The Site Is Hosted On GitHub Pages. When You Request A Page, GitHub May Log Ordinary Connection Data Such As Your IP Address, The Page Requested And Your Browser's User Agent, As Any Web Host Does, In Order To Serve The Page And Keep The Service Secure And Working. That Logging Is GitHub's, Not Ours, And Is Described In GitHub's Privacy Statement. We Are Not Given Those Logs And We Do Not Read Them.
